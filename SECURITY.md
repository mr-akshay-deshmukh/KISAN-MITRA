# Security Policy

## Supported Versions

We provide security updates and patches for the following versions of KisanMitra:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The KisanMitra team takes the security of our platform and the protection of farmer and buyer data seriously.

If you discover a security vulnerability within KisanMitra, please **do not open a public issue**. Instead, follow these steps:

1. **Email us directly** at `engineeringstudies5@gmail.com` with the subject line: `[SECURITY] Potential vulnerability in KisanMitra`.
2. **Include comprehensive details**:
   - Detailed description of the vulnerability.
   - Proof-of-concept (PoC) or step-by-step reproduction instructions.
   - Affected components (`server.ts`, `googleAuthService.ts`, `firestore.rules`, etc.).
   - Potential impact on users or data confidentiality.
3. **Response Timeline**:
   - We will acknowledge receipt of your vulnerability report within **48 hours**.
   - We will provide a status update and estimated patch timeline within **7 business days**.
   - Once resolved, a patch will be deployed and you will be credited (if desired) in the release notes.

Thank you for helping keep KisanMitra and our agricultural community safe!
